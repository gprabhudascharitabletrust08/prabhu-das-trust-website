# Prabhu Das Golconda Charitable Trust website

## Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/` (keep the ten existing photo files here, and add `trust-logo.jpg` here)

## Important
Copy `trust-logo.jpg` into the GitHub repository's `assets/` folder alongside the existing `photo-*.jpg` files. Upload the updated HTML/CSS/JS to the repository root. Keep the domain/DNS settings unchanged.

The site includes a horizontally scrollable gallery with arrow controls, WhatsApp chat link, email link, and the donation information supplied by the trust. Verify bank details before public use.
