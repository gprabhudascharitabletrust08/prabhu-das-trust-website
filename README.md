# Prabhu Das Golconda Charitable Trust Website

A responsive static website starter built with HTML, CSS and JavaScript. It can be hosted on GitHub Pages for free and connected to a custom domain later.

## Files
- `index.html` — page content
- `styles.css` — responsive design
- `script.js` — mobile navigation and footer year
- `assets/` — place approved trust photos and logo here

## Before publishing
1. Replace the designed gallery placeholders with approved photographs.
2. Confirm all public contact details and the founder biography with the trust.
3. Add only verified donation/bank details after receiving approval.
4. Confirm the trust is happy for the listed phone number and email to be public.

## Publish with GitHub Pages
1. Create a public GitHub repository named `prabhu-das-trust-website`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
3. In repository Settings → Pages, select deployment from the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.
5. When the custom domain is purchased, enter it in Settings → Pages → Custom domain and configure DNS as GitHub instructs.

Note: Google Fonts require an internet connection. The site remains usable if the font provider is unavailable, using fallback fonts.
